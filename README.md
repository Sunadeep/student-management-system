# Student Management System

A beginner-friendly Python project to manage student records using a simple menu-driven program.

## Features
- Add student records
- View all students
- Search for a student
- Update student marks
- Delete student records
- Handle students who do not exist

## Technologies Used
- Python
- Dictionaries
- Functions
- Loops and conditional statements

## How to Run
1. Install Python.
2. Download `student_management.py`.
3. Open a terminal in the file's folder.
4. Run:

```bash
python student_management.py
```
